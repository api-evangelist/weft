# Weft

Weft was a Burlington, Vermont based supply-chain logistics startup, founded by Marc Held around 2013-2014, that combined hardware sensors and software to track the shipping of physical goods worldwide in real time. It raised a seed round of under $1M led by Andreessen Horowitz (a16z) and Data Elite, with plans for a $5M Series A.

Surfaced as an a16z portfolio company and added to the API Evangelist network as a stub for enrichment.

**Status:** Inactive / defunct. As of the July 2026 enrichment pass no live corporate website, developer portal, or public API surface could be found. Candidate domains were probed and none host an active product (weft.com refused connection, weft.io does not resolve, weft.ai is a parked domain listed for sale).

Backed by: a16z, Data Elite
